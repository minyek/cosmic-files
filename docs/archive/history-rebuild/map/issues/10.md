# #10 Every file is opened and about 18 KB read just to choose its icon [CLOSED]

## Problem

A 481-file folder on a spinning disk spent about 5 s on these reads from a cold cache; with the fix it takes about 17 ms.

## Cause

`mime_for_path` (`src/mime_icon.rs`) always sniffed the contents of local files.

## Fix

`mime_from_file_name` answers from the file name when exactly one glob claims it and the file is a non-empty regular file; other names still read the contents.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`an_unambiguous_name_outranks_the_file_contents`, `a_local_name_that_decides_nothing_still_reads_the_contents`, `a_directory_named_like_a_file_is_typed_as_a_directory`, `an_empty_local_file_with_a_known_extension_keeps_its_named_type`, `symlink_metadata_takes_precedence_over_a_file_extension`.
