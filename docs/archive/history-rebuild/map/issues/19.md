# #19 A context menu over a .desktop file re-parses the file on every frame [CLOSED]

## Problem

With a launcher's context menu open, its `.desktop` file is read and parsed on every frame.

## Cause

`menu::context_menu` called `load_desktop_file` while building the view.

## Fix

The file is parsed once off the UI thread (`Command::ParseDesktopEntry`, `DesktopEntryParsed`) and cached with a work id (`DesktopEntryActions`).

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`pending_and_failed_desktop_parses_keep_the_ordinary_menu`, `a_valid_desktop_entry_without_actions_still_gets_its_launcher_menu`, `a_desktop_parse_cannot_apply_to_a_replacement_item`, `an_obsolete_desktop_parse_cannot_erase_the_selected_launchers_actions`, `an_open_menu_keeps_its_layout_until_the_next_invocation`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
