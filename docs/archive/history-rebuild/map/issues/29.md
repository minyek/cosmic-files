# #29 Search results are built on the UI thread as they stream in [CLOSED]

## Problem

Large searches stutter while results arrive.

## Cause

The `SearchReady` handler called `item_from_search_item` for each result, which counts children, reads headers and parses desktop files.

## Fix

Each item is built in the search worker.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

None direct.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
