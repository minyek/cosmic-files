# #14 Deleting files freezes the window, about 12 s on NTFS or CIFS [CLOSED]

## Problem

Deleting a selection blocks the window while each file is checked.

## Cause

`App::delete` stats each path on the UI thread to choose between the Trash and permanent deletion.

## Fix

The stats run off the UI thread and finish in `Message::DeleteClassified`.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

None specific.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
