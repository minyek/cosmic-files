# #23 The Open-with application cache is built and saved on the UI thread [CLOSED]

## Problem

The window freezes at startup, whenever `mimeapps.list` changes, and when a default application is set.

## Cause

`MimeAppCache::new()` and `reload()` ran in `init` and in the watcher, and `set_default` read, wrote and reloaded inline.

## Fix

`App::refresh_mime_app_cache` rebuilds the cache with `spawn_blocking` and finishes in `MimeAppCacheLoaded`; startup begins from an empty cache, and writes go through an ordered (FIFO) writer.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests
