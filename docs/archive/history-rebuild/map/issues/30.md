# #30 Sidebar Open with and Preview, and breadcrumb Preview, build the item on the UI thread [CLOSED]

## Problem

These actions block the window while the item is read from disk.

## Cause

The item was built inline.

## Fix

It is built off the UI thread (`NavMenuOpenWith`, `Command::PreviewPath`, `PreviewReady` with a request id).

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_current_preview_result_opens_its_item`, `a_preview_result_cannot_reopen_dismissed_details`, `a_preview_result_cannot_replace_newer_context`, `searching_invalidates_a_pending_preview`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
