# #49 Files without an extension on network mounts and in the Trash show as empty files [CLOSED]

## Problem

Such files are typed as `application/x-zerosize` and shown as empty documents.

## Cause

A name-only xdg-mime guess has no contents to check and matches the zero-size type with full confidence.

## Fix

The name's answer is used only when a glob claims the name; otherwise `mime_guess` decides (`is_placeholder_mime`).

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`remote_files_without_metadata_are_not_typed_as_empty`, `remote_file_without_a_known_extension_is_not_typed_as_empty`, `empty_remote_file_is_typed_as_empty`, `remote_file_with_a_known_extension_is_typed_from_its_name`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
