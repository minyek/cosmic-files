# #42 Rename can silently replace an existing file [CLOSED]

## Problem

If a file with the new name appears after the rename dialog checked the name, the rename overwrites it.

## Cause

`Operation::Rename` used a plain `rename`; the dialog's `exists()` check is advisory only.

## Fix

`rename_noreplace` uses `renameat2(RENAME_NOREPLACE)` and reports "already exists". Where that call is unavailable, the rename fails instead of falling back. Renaming to the same name does nothing.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).
