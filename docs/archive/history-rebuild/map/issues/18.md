# #18 The New file, New folder, Rename and Compress dialogs stat the target on every keystroke [CLOSED]

## Problem

Typing a name in these dialogs checks the disk on every key press, which lags on slow mounts.

## Cause

`parent.join(name).exists()` and `is_dir()` ran inside the dialog view.

## Fix

The name check reads the scanned listing (`App::existing_entry_in_dir`, `Tab::find_entry_is_dir`); the operation itself is the authoritative guard against overwriting.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_search_tab_cannot_say_whether_a_name_in_its_root_is_taken`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
