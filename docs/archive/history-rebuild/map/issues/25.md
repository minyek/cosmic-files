# #25 Pressing Enter in the location bar stats and canonicalizes on the UI thread [CLOSED]

## Problem

Submitting a typed path on a slow mount freezes the window.

## Cause

The typed path was resolved with filesystem calls inline.

## Fix

Resolution runs off the UI thread via `Command::EditLocationSubmit`; parsing a typed URI, which does no I/O, stays inline.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_typed_path_submits_as_a_path`, `a_typed_uri_submits_as_a_network_location`, `dialog::tests::submitting_a_picker_location_opens_the_requested_directory`; also `an_unmounted_path_invalidates_pending_navigation`, `sidebar_drop_navigation_invalidates_pending_location_resolution`, `an_older_picker_navigation_cannot_replace_a_newer_request`; also `opening_a_new_tab_invalidates_pending_navigation`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
