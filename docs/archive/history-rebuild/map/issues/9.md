# #9 Opening a large folder on a slow disk shows nothing until every entry is processed [CLOSED]

## Problem

Nothing appears until the whole listing is built, and each entry's stat and MIME sniff run one after another.

## Cause

`scan_path` (`src/scan/path.rs`) processes entries sequentially.

## Fix

Entries are collected first and processed in parallel with rayon (`into_par_iter()`); `.hidden` is read beforehand.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

The existing `scan_path_*` tests, `tab_listing_matches_directory_contents`, `an_entry_named_in_dot_hidden_is_marked_hidden`.

## Upstream

A performance improvement over pop-os/cosmic-files `master` (4efe802).
