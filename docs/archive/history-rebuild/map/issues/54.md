# #54 "Delete permanently" menu entries sent files to the Trash [CLOSED]

## Problem

Holding Shift is meant to turn the menus' delete entry into "Delete permanently", matching the Shift+Delete shortcut. Several entries did not do what they said:

- The menu bar labelled Shift's delete entry "Delete permanently" outside the Trash, but it fired the trash action, so local files went to the Trash.
- The right-click menu for a single selected `.desktop` launcher never offered the Shift entry; it always showed "Move to Trash".
- Inside a folder opened from the Trash, the right-click menu's "Delete permanently" moved the files into the Trash again.

## Cause

In `src/menu.rs`, the menu bar mapped Shift to the label `delete-permanently` with `Action::Delete`. Outside the Trash, `Message::Delete` calls `App::delete`, which trashes local files. The launcher branch of the context menu pushed `move-to-trash` / `Action::Delete` with no Shift check. A folder opened from the Trash is a plain path location, so its "Delete permanently" entry's `Action::Delete` also took the trash path.

## Fix

One helper, `delete_menu_entry`, chooses the label and action for the menu bar and every context-menu delete entry: in the Trash, `Delete` (the delete-from-trash dialog); with Shift and no Ctrl, `PermanentlyDelete`; otherwise "Move to Trash". A trashed folder's children fire `PermanentlyDelete`. `context_menu` is split so tests read the item list (`context_menu_items`).

Landed in 79a17e1.

## Acceptance criteria

- Outside the Trash with Shift (no Ctrl), the menu bar shows "Delete permanently" and fires `PermanentlyDelete`.
- In the Trash, the menu bar shows "Delete permanently" with the delete-from-trash action, with or without modifiers.
- Without Shift, or with Ctrl+Shift, outside the Trash, the entry is "Move to Trash".
- A lone `.desktop` launcher's context menu follows the same Shift rule as other files.
- Inside a folder opened from the Trash, "Delete permanently" deletes permanently.

## Tests

In `menu::tests`:

- `delete_menu_entry_label_matches_its_action`: every location × Shift × Ctrl; the label says "Delete permanently" exactly when the action deletes permanently. It failed against the old mapping.
- `shift_offers_permanent_delete_for_a_lone_desktop_launcher`: failed before the fix.
- `shift_offers_permanent_delete_for_an_ordinary_file`, `the_trash_offers_its_delete_from_trash_entry`.
- `a_trashed_folders_child_is_deleted_permanently`: failed before the fix.
