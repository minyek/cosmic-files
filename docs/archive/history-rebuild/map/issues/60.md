# #60 Log rather than panic when the notification task fails to run [OPEN]

## Problem

If the notification task fails to run, cosmic-files panics while reporting a finished operation.

## Cause

`src/app.rs` called `.unwrap()` on the join result of the `spawn_blocking` task that shows the desktop notification. A failed task (a panic inside the task, or a runtime that is shutting down) turned a missing notification into a panic of the UI thread.

## Fix

The join result is handled with `unwrap_or_else`, which logs `failed to run the notification task: {err}` as a warning and carries on. The operation's own result is unaffected.


## Tests

None: the failure needs the notification task itself to fail.
