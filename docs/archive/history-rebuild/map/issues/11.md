# #11 Drawing icons on the UI thread can stall behind a slow file read [CLOSED]

## Problem

While a scan sniffs a file on a slow mount, every `mime_icon()` call on the UI thread waits for it.

## Cause

`mime_for_path` held the `MIME_ICON_CACHE` mutex across `gb.guess()`, which reads the file.

## Fix

Guessing uses a separate, immutable `SHARED_MIME_INFO`; the mutex now guards only the icon map.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`mime_queries_can_run_while_the_icon_cache_is_in_use`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
