# #45 Files whose names are not valid UTF-8 are silently left out of archives [CLOSED]

## Problem

Compressing a folder that holds such a file produces an archive without it, and no error.

## Cause

Paths whose `to_str()` failed were skipped.

## Fix

TGZ keeps the raw names; ZIP, which cannot store them, fails the operation and creates nothing.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`tgz_preserves_non_utf8_source_names`, `zip_rejects_non_utf8_source_names_without_publishing`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
