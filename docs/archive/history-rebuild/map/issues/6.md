# #6 The sort order is rebuilt with the ICU collator on every layout pass [CLOSED]

## Problem

Sorting cost grows with folder size on every frame: about 14,000 collator comparisons per pass for 1,349 entries.

## Cause

`column_sort` (`src/tab.rs`) allocates and sorts the whole list on each call, and `widget::responsive` calls it inside every layout.

## Fix

`sorted_indices` and `sort_cache` keep the order, keyed by the sort options; `resort_if_ordered_by` rebuilds it only when the changed key is the sort key.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`sort_order_survives_the_cache`, `a_child_count_only_discards_the_sort_order_that_reads_it`, `a_metadata_refresh_only_discards_the_sort_order_that_reads_it`, `capped_search_keeps_new_results_in_modified_order`.
