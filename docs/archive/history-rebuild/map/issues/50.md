# #50 Every file in a network (GVFS URI) listing is typed as a folder [CLOSED]

## Problem

Open with and other type-based actions treat remote files as `inode/directory`.

## Cause

`network_scan` hard-coded `inode/directory` for every entry.

## Fix

`mime_for_file_info` uses `standard::content-type`, then the file name, then `application/octet-stream`.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`regular_file_uses_gio_content_type`, `regular_file_without_content_type_uses_name`, `unknown_regular_file_falls_back_to_octet_stream`, `directory_uses_directory_mime`, `forced_directory_uses_directory_mime`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
