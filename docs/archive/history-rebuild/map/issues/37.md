# #37 Recent files are never recorded on a fresh profile [CLOSED]

## Problem

If `~/.local/share/recently-used.xbel` does not exist yet, nothing is ever added to Recents.

## Cause

recently-used-xbel 1.2.0 `parse_file()` calls `read_to_string`, which fails on a missing file (from the crate source).

## Fix

`recents::initialize_history` creates an empty XBEL file atomically (`persist_noclobber`) before applying a change.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`initializing_history_preserves_existing_contents`, `initializing_history_propagates_storage_errors`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
