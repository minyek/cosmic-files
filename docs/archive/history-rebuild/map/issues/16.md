# #16 The properties pane stats network (GVFS) files on every repaint [CLOSED]

## Problem

With a network file selected, the details pane blocks on the network on every frame.

## Cause

`Item::file_metadata()` called `fs::metadata` for GVFS items; the single- and multi-item panes and the apply-to-all permissions control call it.

## Fix

It is now `cached_metadata()`, which does no I/O. GVFS files no longer show created or accessed times or permissions, and the apply-to-all permissions control skips them.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`cached_metadata_reflects_scan_without_restat`; also `a_trashed_file_reports_its_size`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
