# #27 Updating the file watcher blocks on cold mounts [CLOSED]

## Problem

Navigating to a folder on a cold mount stalls while the watcher is updated.

## Cause

`update_watcher` called `watch()` and `unwatch()` inline.

## Fix

`watcher::reconcile` runs off the UI thread and finishes in `Message::WatcherUpdated`; the file picker does the same. A panic inside `reconcile` hands the watcher back with an empty watch set instead of dropping it, and `WatcherUpdated` reconciles again whenever the returned set no longer matches the open tabs.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`dialog::tests::picker_watch_updates_reconcile_navigation_during_the_worker`; also `panicking_watch_preserves_the_watcher_for_a_later_request`.
