# #52 The default terminal org.gnome.desktop.Terminal resolves to org.gnomeTerminal [CLOSED]

## Problem

A default terminal whose id contains `.desktop` in the middle is not found.

## Cause

`.replace(".desktop", "")` removed the text anywhere in the id.

## Fix

`strip_suffix(".desktop")` removes only a trailing suffix.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_trailing_desktop_suffix_is_dropped`, `a_desktop_segment_inside_an_id_is_kept`, `an_id_without_the_suffix_is_unchanged`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
