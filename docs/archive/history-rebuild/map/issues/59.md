# #59 Name the SVG preview size limit [OPEN]

## Problem

The SVG thumbnail's 8 MB size cap is an unnamed literal next to the named text-preview cap, whose comment called the same decimal value "8 MiB".

## Cause

The built-in SVG thumbnailer in `src/item/thumbnail.rs` passed an inline `8 * 1000 * 1000` to `check_size` with no name, next to the named `TEXT_PREVIEW_MAX_FILE_BYTES` that carries the same limit, so the two limits were easy to confuse and the SVG one had no home of its own.

## Fix

`SVG_PREVIEW_MAX_FILE_BYTES` (8 MB) names the SVG preview limit, and the SVG branch calls `check_size("svg", SVG_PREVIEW_MAX_FILE_BYTES)`. The text preview limit's comment now reads "8 MB", matching its value in decimal bytes.

Found during the history rebuild: the SVG cap had been named inside another issue's commit without an issue of its own.
