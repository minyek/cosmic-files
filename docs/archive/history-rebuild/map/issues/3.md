# #3 Opening or reading any file in an open folder makes the whole folder rescan [CLOSED]

## Problem

Any program that opens a file in the displayed folder, including this app's own thumbnailer, triggers a full rescan. A folder holding a log that is being written rescanned about four times a second.

## Cause

`Message::NotifyEvents` (`src/app.rs`) rescans on every event that is not `Modify(Data|Metadata)`. notify 8.2 reports `OPEN` and `CLOSE_WRITE` as `Access` events, so reads rescan. Data writes also ran `fs::metadata` on the UI thread.

## Fix

`classify_events` ignores `Access` events, re-stats written direct children off the UI thread (`App::refresh_tab_entries`, `Tab::refresh_entries`), and rescans only for structural changes, including a `.hidden` write.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).
