# #13 Opening a folder on a slow mount freezes for 1-2 s, and symlinked favourites never highlight [CLOSED]

## Problem

Clicking a favourite on a network mount blocks the window. A favourite that is a symbolic link loses its highlight, because its path is rewritten to the target.

## Cause

`Location::normalize()` ran `fs::canonicalize` and `is_dir()` on every navigation, result, title and sort key; `folder_name` also called `fs::metadata`.

## Fix

`normalize()` makes no filesystem calls (lexical normalisation and tilde expansion). Telling files from folders and resolving symlinked parents happen off the UI thread (`src/navigation.rs`, `Message::LocationSelect`). Symlinked folders get a new per-folder sort key once.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).
