# #34 Blocking filesystem calls run on the async runtime [CLOSED]

## Problem

The overwrite-conflict dialog blocks an async worker thread with filesystem calls.

## Cause

The conflict dialog's items were built with `item_from_path` directly in `handle_replace`.

## Fix

`build_replace_item` builds them in `spawn_blocking`.

## Tests

None.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
