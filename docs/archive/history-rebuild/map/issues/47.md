# #47 New folder in the file picker does nothing visible when it fails [CLOSED]

## Problem

If the file picker cannot create a folder, nothing appears and no error is shown.

## Cause

The picker's `NewFolder` completion only logged the `create_dir` error.

## Fix

The folder is created off the UI thread and reported in `Message::FolderCreated`; on failure the dialog reopens with the error.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_failed_folder_creation_reports_in_the_dialog`, `a_created_folder_opens_in_the_picker`; also `a_created_folder_cannot_replace_newer_navigation`, `a_failed_folder_creation_cannot_reopen_a_cancelled_picker`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
