# #20 Opening files sniffs each file's type on the UI thread first [CLOSED]

## Problem

Opening a selection blocks the window while each file's type is read.

## Cause

`open_file` ran `mime_for_path` for each path inline.

## Fix

Sniffing runs off the UI thread, and launching happens in `Message::OpenFileClassified` (`OpenTargets::classify`, `open_classified`).

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`archives_open_in_the_order_they_were_given`, `one_non_archive_groups_every_path_by_mime`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
