# #26 Several actions re-stat items that were already scanned [CLOSED]

## Problem

Open in new tab or window, Rename, the preview's Open button and dropping onto a folder each checked the disk again on the UI thread.

## Cause

Inline `is_dir()` and `read_dir(target)` calls.

## Fix

Decisions use the scanned metadata (`Tab::selected_paths_with_dir`), and drop filtering compares parent paths.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`selected_paths_report_their_directory_flag_without_restating`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
