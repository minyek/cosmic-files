# #22 Clicking a network favourite blocks while its existence is checked [CLOSED]

## Problem

Selecting a network favourite in the sidebar freezes the window until the server answers.

## Cause

`on_nav_select` called `try_exists()` inline for network locations.

## Fix

The check runs off the UI thread and continues in `Message::NavSelectChecked`; a favourite that points at a file now opens the file.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

None direct; also `an_obsolete_mount_cannot_redirect_the_active_tab`, `a_current_mount_continues_the_requested_navigation`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
