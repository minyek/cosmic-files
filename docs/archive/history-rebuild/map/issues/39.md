# #39 Gallery image bookkeeping grows with every image viewed [CLOSED]

## Problem

Viewing many images in the gallery grows memory without bound.

## Cause

`LargeImageManager::clear_cache` (`src/large_image.rs`) cleared only the decoded images; its size, error and generation maps kept growing.

## Fix

They are cleared together. Generations only increase, and a failed decode clears only its own generation.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`clear_cache_clears_orphan_maps_and_retains_in_flight_generations`, `a_late_result_cannot_repopulate_a_cleared_cache`, `only_the_current_decode_failure_clears_in_flight_work`.
