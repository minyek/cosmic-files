# #43 Compress overwrites an existing archive and leaves partial archives behind [CLOSED]

## Problem

Compressing to a name that already exists truncates that file, and a failed or cancelled compress leaves a partial archive.

## Cause

`fs::File::create(&to)` wrote straight to the destination.

## Fix

The archive is written to a staged temporary file (`atomic_file::stage`), synced, checked for cancellation, and published with `persist_noclobber`.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`compress_preserves_an_existing_zip`, `compress_preserves_an_existing_tgz`, `failed_zip_leaves_no_destination`, `failed_tgz_leaves_no_destination`, `cancelled_zip_leaves_no_destination`, `cancelled_tgz_leaves_no_destination`, `published_zip_is_readable`, `published_tgz_is_readable`.
