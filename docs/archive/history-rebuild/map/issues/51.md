# #51 Without the desktop feature, the launcher menu appears for several selected files and for folders named *.desktop [CLOSED]

## Problem

The launcher context menu is offered when it does not apply.

## Cause

The selection-count check sat inside `#[cfg(feature = "desktop")]`, and the extension match did not check the file type.

## Fix

`lone_desktop_entry` requires exactly one selected regular file.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_desktop_entry_among_several_selected_items_is_not`, `a_lone_desktop_entry_is_offered_its_own_menu`, `a_lone_selected_file_that_is_not_a_desktop_entry_is_not`, `an_unselected_desktop_entry_is_not`, `review_a_directory_with_a_desktop_suffix_keeps_its_folder_menu`, `a_desktop_suffixed_socket_is_not_a_launcher`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
