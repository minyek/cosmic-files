# #7 List and grid views build widgets for every row, not just the visible ones [CLOSED]

## Problem

A 20,000-entry list took 18.9 ms per frame, too slow for 60 fps.

## Cause

Each off-screen row still got a placeholder and a separator (list) or a spacer (grid). Button ids came from `widget::Id::unique`, which follows tree position rather than the item.

## Fix

One spacer stands in for each run of off-screen rows; the grid's leading and trailing spacers sit outside the grid. `next_button_id` gives each item a stable id, so focus stays on the right item while scrolling.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).
