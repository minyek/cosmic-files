# #48 Trashed images show the dimensions of a different file [CLOSED]

## Problem

A trashed image shows no dimensions, and once a new file takes its original name it shows that file's dimensions.

## Cause

`item_from_trash_entry` read `image_dimensions` from the original path.

## Fix

It reads the trashed copy.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`trash_item_reads_image_dimensions_from_the_trashed_file`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
