# #33 The file picker blocks its window on slow mounts [CLOSED]

## Problem

The open and save dialogs freeze while they check paths on slow mounts.

## Cause

Six blocking calls in `src/dialog.rs`: `canonicalize` in `Dialog::new`, `is_dir` per favourite, inline `create_dir`, `fs::metadata` on watch events, and `is_dir` and `exists` in Open and Save.

## Fix

The picker follows the main window's fixes (off-thread work, cached metadata); Save checks its target off the UI thread (`SaveChecked`), tied to that exact target.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests
