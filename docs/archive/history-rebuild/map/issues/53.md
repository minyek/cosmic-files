# #53 A .desktop action can run a different command from the one clicked [CLOSED]

## Problem

If the launcher file or the selection changes after its context menu opens, clicking an action can run another action's command.

## Cause

`ExecEntryAction` re-parsed the selected file on click and ran the action at the clicked index.

## Fix

The menu carries the parsed actions (`DesktopAction { name, exec }`) with a snapshot id, and a stale snapshot runs nothing.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_desktop_action_keeps_the_command_shown_in_its_menu`, `an_obsolete_menu_cannot_run_a_new_snapshots_action`.
