# #4 Scanning a folder of folders reads every subfolder to show its item count [CLOSED]

## Problem

Each subfolder costs one more directory read, nearly all for rows that are off screen. This is slow on cold caches and network mounts (measured: 160 ms to 107 ms of CPU for 1,349 entries).

## Cause

`item_from_entry` (`src/item/mod.rs`) called `fs::read_dir(&path).count()` for every directory.

## Fix

The scan leaves the count empty. `Tab::subscription` counts only visible directories (all of them when sorting by size), and the count arrives as `Message::DirectoryChildren`. Unreadable folders are remembered so they are not retried every frame.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`scan_path_leaves_child_counts_for_the_visible_rows`, `directory_children_message_fills_in_the_count`, `size_ordering_reads_child_counts_for_off_screen_rows`.

## Upstream

A performance improvement over pop-os/cosmic-files `master` (4efe802).
