# #8 Scrolling text files into view freezes the window, sometimes for seconds [CLOSED]

## Problem

Each text file that scrolls into view gets a shaped text preview. One file took 3.3 s, and 289 files used 1.7 GB.

## Cause

Thumbnails were requested for every visible row. `text_editor::Content` holds the process-wide font-system lock while shaping up to 256 KiB (`TEXT_PREVIEW_MAX_BYTES`), yet no row shows that preview.

## Fix

`Tab::thumbnail_is_displayed` builds text previews only for the gallery and the preview pane, and the cap is 16 KiB.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`a_text_preview_is_built_only_where_one_is_rendered`, `a_text_preview_is_capped_at_what_the_preview_can_show`, `a_standalone_preview_item_carries_no_shaped_text`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
