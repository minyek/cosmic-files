# #15 The properties pane re-reads an image file on every repaint [CLOSED]

## Problem

With an image selected, every mouse move reopens the file, and the gallery reads the image header again on each decode.

## Cause

`Item::preview_view` called `image::image_dimensions(path)` every frame, and `LargeImageManager::try_decode` read the header again.

## Fix

Dimensions come from the accepted thumbnail work (`Item::image_dimensions`), and the gallery reuses them.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`review_a_local_thumbnail_populates_image_details`, `cached_thumbnails_do_not_invent_original_dimensions`, `stale_thumbnail_dimensions_cannot_populate_a_replacement`, `external_thumbnail_without_image_dimensions_does_not_start_a_decode`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
