# #31 Launching a .desktop file parses it on the UI thread [CLOSED]

## Problem

Opening a launcher blocks the window while its file is parsed.

## Cause

`launch_desktop_entries` called `DesktopEntry::from_path` inline.

## Fix

Parsing runs in `spawn_blocking`.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

None.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
