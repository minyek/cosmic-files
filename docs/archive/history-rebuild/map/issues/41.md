# #41 The text of the Failed operations dialog cannot be copied [CLOSED]

## Problem

An error message in the failed-operations dialog cannot be selected, so it cannot be pasted into a bug report.

## Cause

The error was shown with `widget::dialog().body()`, which is plain, unselectable text.

## Fix

A Copy to clipboard button (`Message::CopyText`, i18n key `copy-to-clipboard`) copies the exact text the dialog shows (`failed_operation_text`, `failed_operations_text`).

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests
