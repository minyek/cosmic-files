# #5 Every rescan throws away thumbnails and other computed results [CLOSED]

## Problem

After any rescan, every visible thumbnail, folder size and checksum is computed again, with MIME sniffing and thumbnail-cache probes.

## Cause

`Tab::set_items` kept only the selection and highlight.

## Fix

`ItemCarryover` moves finished results (thumbnail, icons, dimensions, size, checksums, child count) to the new item when its location and fingerprint (mtime, size) match. An observed write always invalidates them; recursive folder sizes are always recomputed.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests
