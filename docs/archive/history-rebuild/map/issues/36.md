# #36 A folder whose watch failed never updates live again [CLOSED]

## Problem

If registering the file watch for a folder failed once, the folder stopped refreshing on changes for the rest of the session.

## Cause

`update_watcher` recorded every requested path as watched even when `watch()` failed, so it was never retried.

## Fix

`watcher::reconcile` returns only the paths that registered; failed ones are retried on the next update.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`watcher::tests::failed_watch_can_be_retried_after_the_directory_appears`; the main-window and picker `a_failed_watch_does_not_resubmit_without_a_new_request`.
