# #24 Open in terminal waits for an xdg-mime process every time [CLOSED]

## Problem

Each use of Open in terminal blocks the window while `xdg-mime` runs.

## Cause

`MimeAppCache::terminal()` started `xdg-mime` and waited for its output.

## Fix

The default terminal is found during the off-thread cache reload and kept in `default_terminal_id`.

Landed in 66dac3f (feat: improve file browsing and show symlink folder badges).

## Tests

`the_cached_default_terminal_outranks_the_fallback`, `an_uninstalled_default_uses_the_preferred_fallback`, `any_installed_terminal_is_a_last_resort`, `an_empty_cache_has_no_terminal`.

## Upstream

The defect is present in pop-os/cosmic-files `master` (4efe802).
